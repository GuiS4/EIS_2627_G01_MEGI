# Entreprise-Information-System (CourierFlow)

Courier Management System developed for the Enterprise Information Systems course (FEUP).

## Project Structure

```text
├── assets/                 # Static assets, icons and images
├── css/                    # Stylesheets
│   ├── client.css          # Client dashboard styling
│   ├── courier.css         # Courier dashboard styling
│   ├── login.css           # Login page styling
│   ├── register.css        # Registration page styling
│   └── style.css           # Global layout and base styling
├── js/                     # Client-side scripts
│   ├── client.js           # Client dashboard logic & map handling
│   ├── courier.js          # Courier dashboard logic & status management
│   └── main.js             # Authentication, local session & shared utilities
├── client.html             # Client portal
├── courier.html            # Courier portal
├── index.html              # Landing page
├── login.html              # User login
└── register.html           # User registration
```

## Running the Application

Open `index.html` in any modern web browser or serve it using an HTTP server (e.g., VS Code Live Server).
